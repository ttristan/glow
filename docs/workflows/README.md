# Workflows

Use this index to map workflow requests to their procedure. Read and follow the linked doc when asked to run a workflow.

## PR review workflow

“Run the PR review workflow” or “run hourly PR review” means follow [pr-review.md](pr-review.md): poll open GitHub PRs every minute for one hour, review/fix eligible PRs under its claim and coordination rules, merge only when its checks pass, then report outcomes and remaining claims.
