# Maintaining AGENTS.md

Keep root `AGENTS.md` short: project purpose, non-obvious tools or commands, and rules that matter across tasks. Put specialized workflows and conventions in focused docs; link them for progressive disclosure. In a monorepo, use nested `AGENTS.md` only for package-specific guidance.

Prefer stable concepts and capabilities over file maps. Before adding a rule, check whether it is actionable, nonredundant, current, and relevant repo-wide. Remove stale or conflicting guidance; avoid generated boilerplate and duplicating existing docs.

Source: [A Complete Guide To AGENTS.md](https://www.aihero.dev/a-complete-guide-to-agents-md).
