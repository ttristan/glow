# The Quiet Reach

A self-contained browser prototype exploring Glow's calm gather, grow, and build loop. Open `index.html` in a browser; no server or dependencies are required. Choose a tool and click tiles to gather wild blooms and stones, plant blooms, lay stones, or build lanterns. Blooms mature after five seconds and can be gathered again. Spend five seeds on an upgrade to double future gathering yields. Number keys 1–4 select tools, and Start over resets the clearing.

This is a local, ephemeral design experiment, not a server-authoritative or persistent game.
