# The quiet field

A self-contained browser prototype exploring Glow's principles: wander a meadow, gather plants and stone, place lights, and upgrade gathering reach. Open `index.html` in a modern browser. Move with WASD or arrow keys and gather with Space or the button. Resources and placed lights last for the current page session only.

This is a design prototype, not a server-authoritative implementation or a decision about Glow's production architecture.
