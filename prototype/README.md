# Lantern Garden prototype

Open `index.html` in a modern desktop browser. Move with WASD or arrow keys, gather nearby flowers and trees with Space, and place lanterns with L or the button. Spend resources on a gathering-range upgrade. Your meadow is saved in browser local storage; Start over clears that saved progress after confirmation.

This is a standalone, local design prototype: its world and rules run in the browser, with no shared world or server authority. It explores a calm, open-ended gathering and building loop rather than defining Glow's production architecture.
